# Privacy Policy — Monocle | Google Images Fullscreen Viewer

_Last updated: 12 September 2026_

## Summary

Monocle does not collect, store, transmit, or sell any data. There are no
accounts, no analytics, no tracking, and no servers. Everything the extension
does happens locally in your browser.

## What Monocle does

Monocle runs on Google Images search result pages. It reads the search results
already present on the page in order to display them in a fullscreen viewer,
and it adds its own interface to that page. This reading happens entirely in
your browser's memory, for as long as the page is open. Nothing is recorded,
saved to disk, or sent anywhere.

## Data we collect

None.

Specifically, Monocle does not collect:

- Personally identifiable information (name, address, email, age, ID numbers)
- Health information
- Financial or payment information
- Authentication information (passwords, credentials, security questions)
- Personal communications (email, messages, chats)
- Location data
- Web browsing history
- User activity (clicks, mouse position, keystrokes, scroll)
- Website content

## Network requests

Monocle makes no network requests of its own, with one exception, which happens
only at your explicit request:

**Copying an image.** If you use the Copy action and have enabled the optional
"image copying" setting, Monocle fetches that one image directly from the site
hosting it, so the image data can be placed on your clipboard. That request goes
from your browser to that image's host, exactly as it would if you opened the
image yourself. It is not routed through us, and we receive nothing from it.

This optional setting is off by default. With it off, Copy places the image's URL
on your clipboard as text, which requires no network request at all. You can turn
the setting on or off at any time from the extension's options page.

## Permissions

- **Access to google.com** — required for the viewer to run on Google Images
  search result pages.
- **Access to all sites (optional, off by default)** — requested only if you
  enable image copying, because image results are hosted on arbitrary domains
  and the image you want to copy could be on any of them. Revocable at any time
  from the extension's options page.
- **Downloads** — used to save an image when you press D or click the download
  button, and at no other time.

## Third parties

Monocle does not share data with third parties, because it does not collect any.
No advertising networks, no analytics providers, no data brokers.

## Children's privacy

Monocle collects no data from anyone, including children.
